# IX Collab Noord — one-page website

Een eenvoudige, responsive statische website op basis van de projectdocumenten en de uitgewerkte inhoudsstructuur voor IX Collab Noord. De vormgeving volgt het visuele systeem van Design Regio Noord Nederland: CMYK-lijnen, vaste richtingen, transparante overlappingen, een rationeel raster en veel witruimte.



## Bestanden

- `index.html` — structuur en webteksten
- `css/styles.css` — volledige vormgeving en responsive gedrag
- `js/main.js` — mobiel menu, navigatie, formulierdemo en jaartal
- `assets/placeholders/` — CMYK-weaving PNG-placeholders met de afmetingen in beeld
- `assets/weaving/` — schaalbaar lijnweefsel voor donkere secties
- `content/homepage.md` — alle inhoud in bewerkbare Markdown
- `tools/generate_placeholders.py` — hulpscript om de placeholders opnieuw te maken
